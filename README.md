# Blogr Landing Page

![Blogr Landing Page](./public/images/logo.svg)

## Overview

This is my solution to the [Blogr landing page challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/blogr-landing-page-EX2RLAApP).

### The Challenge

Users should be able to:

- View the optimal layout for the site depending on their device's screen size
- See hover states for all interactive elements on the page
- See all sections animate in smoothly as they scroll down
- Toggle between light and dark mode
- Navigate using keyboard only

## Features

### Core
- ✅ Fully responsive layout (mobile 375px to desktop 1440px)
- ✅ Interactive navigation with dropdown menus
- ✅ Mobile hamburger menu with accordion dropdowns
- ✅ Hover states on all interactive elements

### Bonus
- ✅ Smooth scroll animations using Framer Motion
- ✅ Dark mode toggle
- ✅ Accessibility improvements — aria labels, keyboard navigation, escape key to close menus
- ✅ Custom loading splash screen
- ✅ Performance optimization — lazy loading sections and images

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/RashMinaj/Blogr-landing-page
```

2. Navigate into the project:
```bash
cd blogr-landing
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```
